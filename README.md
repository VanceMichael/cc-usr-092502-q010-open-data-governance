# 开源数据协作与质量基准发布

维护开源数据集的授权、版本谱系、质量审核和质量基准。

## 参与方与事实

主要参与方包括数据贡献者、合规审核员、质量复核员、平台管理员。领域资料记录以下已经确认的事实：

- 世界数据组织专委会聚焦开源数据集、权威质量体系和专家网络
- 专委会将建设全球开源数据协作平台
- 首批会员单位超过100家并覆盖20余个国家和地区

## 业务约束

- 授权兼容
- 敏感字段脱敏
- 版本冻结
- 基准快照
- 公开引用

`contracts/context.schema.json` 描述资料结构，`fixtures/context.json` 提供不含真实身份信息的示例，`src/data_context.py` 负责读取和校验这些资料。

## 开发命令

运行测试：

```bash
python3 -m unittest discover -s tests -v
```

编译检查：

```bash
python3 -m compileall -q src
```

两条命令只读取仓库内文件，不需要连接外部业务系统。
